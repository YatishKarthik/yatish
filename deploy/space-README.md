# CELESTRA · TerraMappers

Find places on Earth whose ground behaves like a proposed Moon or Mars base site, see what each one can and cannot stand in for, and fly the same hardware mission on both worlds. NASA Space Apps Challenge 2026.

Data: NASA PDS (LRO LOLA, LRO Diviner, MRO HiRISE), NASA Worldview (MODIS), ESA Copernicus (DEM, Sentinel-2). Source code and full documentation are in the project repository.
